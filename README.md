# Ocasio Simple Maintenance Mode

A clean, modern maintenance mode splash page. Take your site offline for visitors with one click while admins browse normally. Part of the lightweight **Ocasio Plugins** suite for WordPress.

---

## Features

* **1-Click Maintenance Mode:** Instantly take your site offline for visitors with a single toggle switch.
* **Admin Bypass:** Logged-in administrators browse, test, and edit the site normally.
* **SEO Safe (HTTP 503):** Automatically sends HTTP 503 Service Unavailable headers to preserve search engine rankings.
* **Custom Branding:** Add your custom headline, message body, and brand logo via the native WordPress Media Library.
* **1-Click Live Preview:** View the exact visitor splash screen directly from your settings screen without logging out.
* **Zero Bloat:** Lightweight PHP and clean CSS with zero external library overhead.
* **Full Suite Integration:** Managed directly from the unified **Ocasio Plugins** menu at position 65.

---

## Installation

1. Click the green **`< > Code`** button at the top of this repository and select **Download ZIP** (or download from [Releases](../../releases)).
2. In your WordPress admin dashboard, navigate to **Plugins -> Add New Plugin -> Upload Plugin**.
3. Choose the downloaded `ocasio-simple-maintenance-mode.zip` file and click **Install Now**.
4. Click **Activate Plugin**.
5. Manage settings under **Ocasio Plugins -> Maintenance**.
